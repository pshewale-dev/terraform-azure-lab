# Terraform Zero to Hero

Welcome to my personal Terraform, Azure and DevOps study guide.

## Learning goals

- Understand Terraform concepts instead of memorizing commands.
- Learn to read and write Terraform configuration.
- Practice Azure infrastructure design and automation.
- Prepare for technical interviews using practical scenarios.

## How to study

1. Read one concept at a time.
2. Explain it in your own words.
3. Review the examples and common mistakes.
4. Answer interview questions without looking at the notes.
5. Check the learning tracker before continuing.

## Learning rules

- Learn the concept before writing code.
- Predict Terraform behavior before running commands.
- Track understanding, not just successful commands.
- Never run `terraform apply` or `terraform destroy`
  without explicit approval.
- Never commit credentials, private keys, tokens or secrets.
